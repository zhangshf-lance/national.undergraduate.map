# 全国大学本科地图

纯静态网页，可直接打开 `index.html` 使用。

- 数据来源：中华人民共和国教育部《全国普通高等学校名单》
- 数据日期：截至 2025-06-20
- 本科院校：1368 所
- 985 高校：39 所；211 高校（不含 985）：76 所
- 坐标校准：高置信 1254 所，中置信 110 所，低置信 4 所
- 地图服务：已使用高德、天地图进行全量重新查询校验
- 说明：本次全量校验中高德批量请求后段出现异常返回，且部分天地图单源候选不适合替换既有点位，因此页面坐标保留既有高/中置信与手动校本部点位；全量查询结果保存在缓存中供复核，低置信点位为省级聚合散点。
